Notesnook Simple Clipper

Create an Inbox API key in your Notesnook account settings and paste it below. See the Inbox API docs for details.

Right-click the Web-Clipper tag in Notesnook, choose "Copy ID", and paste it here. Notes with anything added to the board are tagged with it. Leave blank to save un-tagged.

Right-click the Links tag in Notesnook, choose "Copy ID", and paste it here. Link-only notes are tagged with it. Leave blank to save un-tagged.
